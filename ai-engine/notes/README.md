# Course notes

The tutor answers from the files in this folder. Everything here now is **sample material**: replace it with your real syllabus notes.

- One folder per subject, named the way students pick the subject in the app (`Physics`, `Mathematics`, ...).
- Put `.md` or `.txt` files inside. Use `#` headings to split a file into topics; each section is searched on its own.
- Write in plain sentences. Malayalam notes work too, but a question is matched to notes in the same language.
- Edits are picked up automatically, no server restart needed.
- Test what the tutor will find: `python -m holox_ai "your question" --subject Physics` (run from the `ai-engine` folder).
